
Unsere Hauptplatform soll Konsole sein, das Spiel soll also primär mit Controller gespielt werden. 

Der Spieler soll sich 360grad bewegen können mithilfe des Joy Sticks. 

(XBOX Controller): 

Joy Stick => Bewegung in 360 grad

A Taste drücken => Nahkampfschlag
B Taste drücken => Fernkampf Angriff

Shoulder oder Trigger Taste => Dash/Sprint

Start Button => Pausenmenü öffnen

Im Menü: 
A Taste => Eingabe bestätigen
B Taste => Back Taste

Joy Stick = Auswahlmöglichkeiten in Menüs

Bonus Pausenmenü: Start Taste schließt Pausenmenü
